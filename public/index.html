2

3

✉️ Classic API
1
Enter your API key above.
2
Fill in To and From addresses, subject and HTML body.
3
Adjust tracking and consent options as needed.
4
Click Send via API and review the response.
📡 Classic SMTP
1
Find your SMTP Token in CM under Transactional → SMTP Settings.
2
Paste the token above — it's used as both username and password.
3
Select a port (try 2525 first) and fill in recipients and content.
4
Use Diagnose Connection if sends are timing out.
